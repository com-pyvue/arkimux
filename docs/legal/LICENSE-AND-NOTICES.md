# Licence and distribution guide

Draft for owner review, prepared 5 November 2026. This guide does not replace or
add conditions to [LICENSE](../../LICENSE).

## Source and applications

ArkiMux-authored source in this repository uses Apache-2.0 unless a file states
otherwise. That includes the Local SDK, runtime, CLI, Local UI and ArkiMux-authored
scaffold content. Third-party files retain their own terms. Local and commercial
use do not require an additional ArkiMux framework licence.

You choose your application's licence and retain your rights in your own added
workflows, adapters, prompts, inputs and results. ArkiMux dependencies and copied
scaffold content keep their existing licence and attribution. Provider terms,
input rights and third-party output rights remain separate; this is not a promise
that all model output is exclusively owned or free of third-party rights.
See [Generated project rights](../../GENERATED_PROJECTS.md).

## Redistribution

Follow the actual [Apache licence](../../LICENSE), including its redistribution
and change-notice requirements. Keep applicable attribution and third-party
licences. [NOTICE](../../NOTICE) is informational and does not change the licence.
The code licence does not itself grant ArkiMux branding permission.

The source [dependency inventory](../../THIRD_PARTY_NOTICES.md) includes test,
development and optional packages as well as runtime dependencies. It is not a
claim that every listed package ships in every artifact, or that all dependencies
use Apache-2.0. Inspect the exact bundled dependency closure before distributing
an npm package, executable or image, and carry the terms and notices that apply
to that artifact. Do not remove a copyleft or attribution obligation merely
because the surrounding ArkiMux source uses Apache-2.0.

## Release checks

Before publication, identify the exact source commit and package versions; check
licence and notice inclusion in the actual packed files; verify generated-project
rights references; and retain each artifact's dependency inventory. A draft source
pack is not completion of those checks. Unreleased package versions or a moving
branch must not be described as an accepted stable release.

Later website or service terms must not be used to revoke or narrow the Apache
rights already granted for released code. Managed hosting, maintained deployment
services and any future commercial contract need their own explicit scope; they
are not granted or purchased by downloading Local.
